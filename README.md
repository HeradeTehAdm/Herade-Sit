# Herade Sit

Fabric-мод для Minecraft Java Edition 26.3. Позволяет игроку садиться на ступеньки и полублоки.

## Совместимость

- Minecraft: 26.3
- Fabric Loader: 0.20.1 или новее совместимой ветки
- Fabric API: 0.166.2+26.3
- Java: 25 или новее

## Управление

1. Введите `/sit`, чтобы включить режим сидения.
2. Нажмите ПКМ по ступеньке или полублоку, чтобы сесть.
3. Нажмите Shift, чтобы встать.
4. Повторно введите `/sit`, чтобы выключить режим.

Двойное нажатие Shift не используется. После выхода с сервера режим сидения выключается.

## Как устроена посадка

- Посадка создаётся серверной частью игры; синхронизация положения выполняется через обычную механику пассажиров Minecraft.
- Для места используется невидимая сущность, к которой присоединяется игрок.
- Положение места рассчитывается по форме блока, поэтому учитываются нижние и верхние ступеньки, а также верхние и нижние полублоки.
- При выходе из сидячего положения, отключении игрока или смерти временная сущность удаляется.

## Сборка

Требуется JDK 25 и Gradle версии, указанной в CI.

```bash
gradle build
```

Готовый JAR появится в `build/libs/`.
