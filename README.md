# Herade Sit

Fabric-мод для Minecraft Java Edition 26.3.

## Совместимость

- Minecraft: 26.3
- Fabric Loader: 0.20.1
- Fabric API: 0.166.2+26.3
- Java: 25 или новее

## Задуманная механика

- Команда `/sit` включает или выключает режим сидения.
- При включённом режиме игрок сможет садиться на ступеньки и полублоки.
- Двойное нажатие Shift не используется.
- Для посадки планируется нажатие ПКМ по подходящему блоку.
