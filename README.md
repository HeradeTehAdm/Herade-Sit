# Herade Sit

Fabric-мод для Minecraft Java Edition 26.3.

## Совместимость

- Minecraft: 26.3
- Fabric Loader: 0.20.1
- Fabric API: 0.166.2+26.3
- Java: 25+

## Задуманная механика

Команда `/sit` включает или выключает режим посадки. При включённом режиме игрок сможет садиться на ступеньки и полублоки. Двойное нажатие Shift не используется.

Проект находится в разработке. Готовность и совместимость будут отмечаться только после фактической сборки и проверки.
